Sona Planner

A modern planner and productivity web application built with React, TypeScript, and Supabase.

The project is designed to provide a clean and responsive interface for organizing tasks, managing schedules, and keeping personal workflows structured.

🚀 Live Demo

Demo: https://sona-planner-3opxu3r9g-miras-projects-e9fd58eb.vercel.app/auth

✨ Features

- Email authentication
- Google OAuth login
- GitHub OAuth login
- Protected routes
- Responsive UI
- Form validation
- Real-time backend with Supabase
- Modern dashboard architecture

🛠 Tech Stack

Frontend

- React
- TypeScript
- Vite
- React Router
- Tailwind CSS

State Management

- TanStack Query
- React Hook Form
- Zod

Backend

- Supabase
- Authentication
- Database

UI Components

- Radix UI
- Recharts

📦 Installation

Clone the repository:

git clone https://github.com/MirasSarsen/sona-planner.git

Install dependencies:

npm install

Run locally:

npm run dev

Build:

npm run build


🎯 Project Goal

This project was built to practice modern frontend architecture and full-stack integration using React and Supabase while following production-oriented development practices.
